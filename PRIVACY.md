# Privacy Policy

This plugin connects Dify to Treza (https://www.trezalabs.com), operated by Treza Labs, Inc.

## What the plugin sends, and where

When a Treza tool runs, the plugin sends these to Treza's API at `www.trezalabs.com` over HTTPS:

- Your **Treza API key**, to identify your Treza account.
- The **tool inputs** you or your app provide: the prompt, shape, length, model, name, spending cap, pipeline ID, pipeline inputs and run ID.

Prompts and pipeline inputs are user content. If someone types personal information into a prompt, that text is sent to Treza as part of the request.

The plugin sends nothing else. It does not send Dify user IDs, email addresses, IP addresses, device identifiers, conversation history or files.

## What the plugin stores

Nothing. The plugin keeps no data, writes no files and has no persistent storage. It does not write prompts, API keys or results to logs. Your API key is stored by Dify as an encrypted credential.

## What Treza does with the data

Treza uses the inputs to make the picture or video you asked for, and keeps the request, the result and its cost in your Treza account so you can see your renders and usage. To render, Treza passes the prompt to the AI model provider for the model that is used. Treza's privacy policy covers this in full: https://docs.trezalabs.com/terms-and-privacy/privacy

## Third parties

- **Treza Labs, Inc.** (`www.trezalabs.com`, `media.trezalabs.com`): receives the data above and serves the finished files.

The plugin contacts no other service.
